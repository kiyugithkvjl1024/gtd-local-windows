# カレンダーの時間表示

PCは上部ナビの「カレンダー」、スマホは「その他」→「カレンダー」を開き、日・週・月を選びます。時刻は日本時間（JST）です。スマホは日、PCは週から始まります。日表示では空白部分を横にスワイプすると前後の日へ移ります。縦のスワイプは時刻をスクロールします。

日・週は縦が時刻、横が日付です。枠の開始位置と高さで開始時刻と所要時間を示し、重なった枠は横に並びます。青は予定、緑は実績です。時刻なしの行動日・期限・外部終日予定は上部に表示します。予定を持つ完了Taskと完了会議は、元の予定と実績を別の枠で比較できます。月は日付ごとの一覧です。

Taskの「予定変更」と「実績調整」は別の編集です。Taskの実績調整は記録を持つ完了Taskに限ります。矢印ハンドルで枠を動かし、「開始」「終了」で端を調整します。変更後の確認画面で保存するまで元の値を維持します。ドラッグの途中はEsc、確認画面はキャンセルで取り消せます。別の操作でTaskが変わっていた場合は、再読込してから動かします。

短い枠も「予定・実績の一覧と時間調整」を開くと、名前・Task詳細・時間調整ボタンを確認できます。枠の高さを増やさず、短い作業と長い作業の時間差を保ちます。

上部の「時刻なし」は日ごとの件数を表示します。項目が多い場合はその欄をスクロールするか、下の一覧から全件を確認できます。保存後は編集ボタンへ戻り、保存結果を表示します。変更した項目が表示範囲外なら表示日入力へ戻ります。保存後の表示を再取得できない場合は、その旨を表示するので再読込してください。

会議は「操作」から完了するとローカル実績を記録し、後から実績を調整できます。Outlook予定と実績は別のプロパティで保持します。会議の移動・端の調整は専用ハンドルを使います。外部予定の書き換えや自動送信は行いません。Google CalendarとTimeTracker NXへの反映は既存の設定・確認手順を使います。

保存結果が分からない場合、入力を保持して同じ変更を再送しません。再読込して記録を確認します。復旧待ちでは編集を止めます。
